# Timio v0.6.3 — PWA Shell

## Goal
Make the mobile Timio experience installable and resilient to temporary network loss without creating a separate mobile app.

## Included
- Web App Manifest with standalone display and Timio branding.
- 192x192 and 512x512 app icons.
- Production-only service worker registration.
- Network-first document navigation with a safe offline fallback page.
- Cache-first same-origin static asset handling.
- API/auth responses are intentionally never cached.
- Online/offline state indicator.
- Browser install prompt when supported by the platform.
- Mobile viewport and safe-area metadata.

## Offline boundary
This is an **offline shell**, not offline CRUD. Business data and mutations still require the API. Timio deliberately avoids caching API responses so stale tenant data and authentication state are not treated as offline truth.

## Validation
- Manifest, service worker, offline page and icons are present.
- ZIP structure checked after packaging.
- Full Nuxt production build is not claimed because the working environment does not have the project's full dependency/native-binding set installed.
