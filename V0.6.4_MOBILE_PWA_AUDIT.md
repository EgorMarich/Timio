# Timio v0.6.4 — Mobile / PWA Polish & Audit

Final mobile/PWA hardening release before Growth/Retention.

## UX / accessibility
- Focus-visible states for keyboard users.
- Reduced-motion support.
- Safer mobile touch targets.
- Safe-area spacing around fixed navigation and sheets.
- Better modal scrolling on mobile.
- iOS Safari form zoom prevention.

## PWA
- Native install prompt remains supported where the browser exposes it.
- iOS Safari gets an explicit Add to Home Screen instruction.

## Date / timezone
- Day navigation no longer serializes a browser-local Date through `toISOString()`.
- Date shifting is performed using UTC calendar arithmetic, avoiding accidental day changes across browser timezones.

## Scope
No offline mutations, provider onboarding, or production infrastructure changes in this release.
