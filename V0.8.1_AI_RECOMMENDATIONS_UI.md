# Timio v0.8.1 — AI Recommendations UI

## Goal
Expose the deterministic Retention Intelligence layer directly on the main “Сегодня” screen so Timio behaves like an operational assistant rather than a separate analytics page.

## Implemented
- Added `RetentionIntelligence` state and loading lifecycle to the main business dashboard.
- Loads `GET /me/businesses/:id/retention/intelligence` on dashboard mount.
- Added **TIMIO INTELLIGENCE** card with:
  - concise explanation;
  - loading/error/empty states;
  - manual refresh;
  - top 3 recommendations;
  - client name, reason, recommendation and score;
  - direct action CTA.
- `offer_repeat_booking` opens the existing retention offer flow.
- `send_reminder` opens the existing smart rebooking flow.
- Client row opens the existing CRM client detail.
- Added responsive styles for mobile.
- Version bumped to `0.8.1`.

## Architecture
AI remains an advisory layer. It does not create bookings or send messages autonomously. Existing deterministic validation and user confirmation remain the source of truth for actions.

```text
Retention Intelligence API
        ↓
Dashboard recommendation card
        ↓
User reviews WHY / WHAT
        ↓
Existing validated action
```
