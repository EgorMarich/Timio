# Timio v0.8.2 — AI Actions

## Цель
Сократить путь от AI-рекомендации до подтверждённого действия владельцем.

## Что изменено
- AI Recommendations UI получил единый обработчик действий `runIntelligenceAction`.
- Для `offer_repeat_booking` используется существующий безопасный Retention Offer flow: проверка клиента, Telegram, последней услуги, свободного окна и серверная валидация перед отправкой.
- Для повторной записи используется существующий Smart Rebook flow: Timio предлагает ближайшее свободное окно, после чего владелец подтверждает создание записи в стандартной форме.
- Во время подготовки действие блокируется, чтобы не создать дубликаты.
- После успешного действия рекомендация помечается как выполненная и intelligence-список обновляется.
- Никаких автоматических необратимых действий без подтверждения владельца.

## Поток
```
AI recommendation
      ↓
one-click action
      ↓
existing deterministic validation
      ↓
owner confirmation / send confirmation
      ↓
action completed
      ↓
refresh intelligence
```

## Ограничение MVP
Действия используют уже существующие проверенные frontend/backend flows; отдельный LLM не требуется. Следующий логичный этап — генерация персонального текста сообщения через YandexGPT в v0.8.3.
