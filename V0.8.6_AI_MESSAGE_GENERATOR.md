# Timio v0.8.6 — AI Message Generator

## Goal

Turn campaign drafting into a controlled AI-assisted workflow. Timio generates a suggested client message, but the deterministic campaign engine remains responsible for recipients, consent, segmentation, booking links and actual sending.

## Backend

`POST /me/businesses/:id/ai/message`

Input supports:
- purpose: `reactivation | appointment_reminder | follow_up | promotion`
- tone: `friendly | professional | warm | short`
- language: `ru | en | es | it | fr | kk | hy`
- channel: `telegram | whatsapp | sms | email`
- optional client context, draft and offered slot.

The endpoint is tenant-scoped and rate limited to 20 requests/minute/user.

## YandexGPT

Production provider uses the OpenAI-compatible Yandex AI Studio endpoint:
- `YANDEXGPT_API_KEY`
- `YANDEXGPT_FOLDER_ID` or `YANDEXGPT_MODEL`
- optional `YANDEXGPT_BASE_URL`, default `https://ai.api.cloud.yandex.net/v1`

The model URI defaults to `gpt://<folder-id>/yandexgpt/latest`.

API keys should be kept server-side. Yandex Cloud documents API-key authorization with `Authorization: Api-Key ...` and recommends scoped keys for AI access.

## Fallback

When YandexGPT credentials are not configured, the endpoint returns a deterministic safe template with `provider: fallback`. This keeps local development and UI testing unblocked.

## Safety/product rule

AI never sends messages automatically. It only produces a draft. Existing campaign/retention endpoints remain the source of truth for recipient selection, marketing opt-out, attribution and sending.

## Frontend

Campaign composer now has:
- tone selector;
- language selector;
- `Сгенерировать` action;
- provider badge;
- fallback indicator.

Generated text is inserted into the editable message field and can be changed before any send action.
