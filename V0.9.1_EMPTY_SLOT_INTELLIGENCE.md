# Timio v0.9.1 — Empty Slot Intelligence

## Goal
Connect real future availability with retention candidates so Timio can answer: “Where is there a free slot, and who should we offer it to?”

## Backend
- Added `emptySlotIntelligence.service.ts`.
- Added `GET /me/businesses/:id/empty-slot-intelligence?days=1|3|7`.
- Uses the existing timezone-safe availability engine.
- Generates service-aware future slots for the selected horizon (starting tomorrow).
- Reuses the deterministic retention engine.
- Matches a candidate only when the service matches their latest completed visit; same-staff matches receive a higher priority.
- Excludes marketing opt-out clients.
- Returns an actionable opportunity with exact `startAt`, service, staff, client, reason and available contact channels.
- No automatic booking or message sending.

## Frontend
- Added “EMPTY SLOT INTELLIGENCE” block to Today.
- Horizon switch: tomorrow / 3 days / 7 days.
- Shows matched opportunities and exact free time.
- Telegram-ready candidates open the existing editable retention-offer flow using the exact suggested slot.
- Candidates without Telegram open the CRM client instead of pretending an offer can be sent.

## Architecture
`Schedule → Available slots → Service compatibility → Retention candidates → Client ↔ slot match → Owner action`

The deterministic engine remains the source of truth for availability and matching. AI is not required for correctness and can later phrase the recommendation/message.
