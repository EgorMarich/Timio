# Timio v0.6.3 — PWA Shell

## Goal
Make the mobile Timio experience installable and resilient to temporary network loss without introducing a second mobile application.

## Included
- Web App Manifest with standalone display and Timio branding.
- 192x192 and 512x512 app icons.
- Service worker registration in production only.
- Network-first document navigation with a safe offline page fallback.
- Cache-first handling for same-origin static assets.
- Explicit exclusion of API/auth responses from caching.
- Online/offline state indicator.
- Browser install prompt when the platform exposes `beforeinstallprompt`.
- Mobile viewport/safe-area metadata.

## Offline boundary
This release provides an **offline shell**, not offline CRUD. Business data and mutations still require the API. Timio deliberately does not cache API responses because stale tenant data and authentication state are unsafe to treat as offline truth.
