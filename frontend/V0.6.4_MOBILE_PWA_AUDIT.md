# Timio v0.6.4 — Mobile / PWA Polish & Audit

## Goal
Final UX hardening of the mobile workspace before Retention/Growth.

## Completed
- Added focus-visible keyboard accessibility treatment.
- Added reduced-motion support.
- Switched app shell/mobile sizing to `100dvh` where appropriate.
- Increased mobile touch targets for navigation and critical appointment/CRM actions.
- Added bottom navigation safe-area spacing so content is not hidden behind the fixed nav.
- Improved modal and mobile-sheet scrolling/overscroll behavior.
- Prevented iOS Safari input zoom by using 16px controls on small screens.
- Added iOS PWA installation guidance for Safari, while keeping the native install prompt for supported browsers.
- Hardened date navigation so shifting a business day is timezone-neutral and does not depend on the browser/server timezone.

## Deliberately not included
- Offline CRUD or local mutation queues.
- Provider credentials.
- Full production build claim: the current environment does not have the complete native dependency set.
